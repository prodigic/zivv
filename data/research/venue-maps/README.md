# Venue map evidence

The query inputs, Census response and receipt document one cached address
batch. Manual results document official venue points and primary open-map
features used when an address could not be uniquely matched. Each record
retains its original venue ID and source. Generated tile URLs reference
on-demand images; raster tiles are not archived here.

OpenStreetMap observations and the retained primary geometry responses are
© [OpenStreetMap contributors](https://www.openstreetmap.org/copyright),
available under the [Open Database License](https://opendatacommons.org/licenses/odbl/1-0/).
The map coordinate database in `data/venue-maps.json` is shared under ODbL;
the individual sources remain attributed. Census observations are US
government data; Wikidata observations are CC0. Operator-published public
coordinate facts and their source links are documented individually.
Application code retains the repository's software license.

These coordinates have stated precision. Street interpolation, building
bounds, campus estimates and festival access points are not verified entrances.
The complete [catalog](../../../docs/research/venue-map-catalog.md) and
[method](../../../docs/research/venue-maps.md) describe their limitations.
