# Venue address research, batch 3

Checked on 2026-10-02. All 217 assigned stable IDs were reviewed: 166 verified, 41 partial, and 10 unresolved. Machine-readable results: [results-3.json](../../data/research/venue-addresses/results-3.json).

Research used official venue/operator pages, municipal and university directories, official festival organizers, and performer announcements. Identity checks used original event text and shared-ledger event links; duplicate aliases retain separate IDs. Verified means both location and official web presence are backed by opened primary evidence, including shared primary-page evidence opened during this research. A primary historical document can establish a former official website without proving it remains active.

Partial notes distinguish indexed sources that could not be opened from addresses retained only from the published data/events.txt or data/venues.txt. Retained input evidence is not independent verification. Private venues have no invented website. Combined rooms and uncertain stage locations retain null addresses. Geographic festivals use public intersections or published entrances.

Dougherty Arts Center at 10550 Albion resolves to Dougherty Valley Performing Arts Center. Jam Cellars at 1030 Main resolves to the ballroom. Mabuhay Gardens and On Broadway have separate addresses; the combined record has a null address. Pro Arts retains its historical location because the current organization is decentralized. Pier 80 uses the published Portola entrance. The outdoor Caravan Stage was not assigned the Caravan Lounge bar address.
