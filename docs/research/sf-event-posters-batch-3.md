# SF event posters: batch 3

Checked 2026-10-10. 16 venues, 219 listed shows; 123 accepted records. Evidence files are in .cache/sf-poster-b3*. The official source HTML was refreshed during this run, then 244 bounded, title-derived event-page candidates were fetched in groups of eight. 116 returned HTTP 200. Only HTTPS pages and actual image MIME responses were accepted. Original source content was treated as evidence.

Accepted eventUrl values are show-specific official detail pages or officially observed show ticket links (Chapel). Date comes from a Google Calendar export dates parameter, explicit Castro event start Date, or Mab Event JSON-LD; promotional images are conservatively event-artwork unless visually proven to be a flyer. No generic logos accepted. Image validation used GET, HTTP success, and image Content-Type or RIFF/WEBP file signature for the mislabelled SeeTickets CDN. No claim of complete coverage where source pagination, JS or blocked images remain.
